 Интернет‑магазин с переключением темы

Простой веб‑магазин на HTML, CSS и JavaScript с возможностью смены цветовой темы 

 Функциональность

Проект реализует следующие возможности:

* **Переключение темы** — кнопка меняет цветовую схему страницы (светлая/тёмная).
* **Каталог товаров** — карточки с изображением, названием, ценой и кнопкой покупки.
* **Корзина** — при нажатии на «Купить» кнопка меняется на «Добавлено», визуально отмечая выбранный товар.

 Как запустить

1. Сохраните код в файл с именем `index.html`.
2. Поместите все изображения (например, `travel2.png`) в ту же папку, что и `index.html`.
3. Откройте `index.html` в любом современном веб‑браузере (Chrome, Firefox, Edge и т. д.).


# HTML
Базовая структура страницы включает:
* заголовок `<h1>` — название магазина;
* кнопку `<button id="theme-btn">` для смены темы;
* контейнер `<div class="cards">` для карточек товаров;
* отдельные карточки товаров, каждая из которых содержит:
    * `<div class="img">` с фоновым цветом и изображением;
    * заголовок `<h3>` — название товара;
    * `<p class="price">` — цена;
    * кнопку `<button onclick="buy(this)">` для добавления в корзину.

 JavaScript

В проекте используются две функции:

1. **`toggleTheme()`** — переключает CSS‑класс `dark` у элемента `<body>`, меняя цветовую схему. Одновременно обновляет текст кнопки:
    * «Синяя тема» → «Жёлтая тема»;
    * «Жёлтая тема» → «Синяя тема».

2. **`buy(btn)`** — управляет состоянием кнопки покупки:
    * если текст кнопки «Купить», меняет его на «Добавлено» и добавляет CSS‑класс `added`;
    * если текст «Добавлено», возвращает «Купить» и убирает класс `added`.

#CSS (неявный)

Хотя явного CSS‑кода в файле нет, предполагается, что:
* класс `dark` задаёт тёмную тему для `<body>`;
* класс `added` изменяет стиль кнопки (например, цвет фона), чтобы показать, что товар добавлен в корзину.

 Примечания

* В коде есть опечатка: в функции `toggleTheme()` текст кнопки при возврате к светлой теме указан как «Синная тема» вместо «Синяя тема». Рекомендуется исправить.
* Все товары используют одно и то же изображение (`travel2.png`). Для реального использования замените `src` на пути к соответствующим картинкам.
* Код содержит синтаксические ошибки в разметке (незакрытые теги, некорректные закрывающие теги `</div class="card">`). Перед использованием рекомендуется проверить и исправить HTML с помощью валидатора.
